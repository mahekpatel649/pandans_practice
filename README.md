# E-Commerce Sales Data Analysis 📊

My first hands-on Data Science project using **Python, Pandas, and NumPy**.

In this project, I explored an e-commerce sales dataset and practiced different data analysis techniques, including:

* Loading and exploring a CSV dataset
* Understanding data types and dataset structure
* Checking missing values and duplicates
* Using `loc` and `iloc` for data selection
* Filtering data using multiple conditions
* Sorting and grouping data
* Using `groupby()` and aggregation functions
* Analyzing revenue, ratings, delivery time, and product categories
* Creating new columns using calculations
* Using `apply()` and lambda functions
* Converting dates with `pd.to_datetime()`
* Extracting year and month from dates

This project helped me understand how **Pandas can be used to explore and analyze real-world style data** and gave me my first practical experience working with a dataset.

🛠️ **Tools & Libraries:** Python, Pandas, NumPy, Google Colab/Jupyter Notebook
